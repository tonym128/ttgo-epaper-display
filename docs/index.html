🚀 How to Host This on GitHub Pages

  1. Push this repository to your GitHub account (make sure it contains the docs/ folder).
  2. Open your GitHub repository in your browser and click Settings → Pages.
  3. Under Build and deployment → Source, choose Deploy from a branch.
  4. Under Branch, select main and the folder /docs, then click Save.
  5. Within 1–2 minutes, GitHub will publish your Web Flasher at https://<username>.github.io/<repo-name>/!
